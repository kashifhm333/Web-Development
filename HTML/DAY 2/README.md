# Day 2 - Basic HTML, CSS & JavaScript

## Overview
Your first practical web development project! This day introduces the fundamental trio of web development: **HTML** (structure), **CSS** (styling), and **JavaScript** (interactivity).

## Files in This Project

### 📄 `index.html`
- **Purpose**: The main HTML structure
- **Content**: A simple webpage about Ronaldo
- **Key Concepts**:
  - HTML5 document structure
  - Meta tags for charset and viewport
  - Linking external stylesheets
  - Basic paragraph content

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ronaldo</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    Ronaldo is the best player in the world.
</body>
</html>
```

### 🎨 `style.css`
- **Purpose**: Styling rules for the HTML
- **Key Concepts**:
  - CSS selectors
  - Colors and fonts
  - Margins and padding
  - Responsive design basics

### ⚙️ `script.js`
- **Purpose**: Interactive behavior
- **Key Concepts**:
  - JavaScript basics
  - DOM manipulation
  - Event handling

## Learning Outcomes
✅ Understand the relationship between HTML, CSS, and JavaScript
✅ Create a basic webpage
✅ Link external stylesheets
✅ Understand document structure
✅ Learn meta tags purpose

## How to View
1. Open `index.html` in your browser
2. Right-click and select "View Page Source" to see the HTML
3. Open browser DevTools (F12) to see CSS and JavaScript in action

## Concepts to Remember
- **HTML**: Content and structure
- **CSS**: Appearance and layout
- **JavaScript**: Behavior and interactivity
