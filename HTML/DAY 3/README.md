### 📄 `Bookmark.html`
- **Purpose**: Demonstrates HTML bookmarks and anchor navigation
- **Key Concepts**:
  - Anchor tags `<a>` for links
  - Named anchors with `id` attributes
  - Internal page navigation
  - Creating a table of contents

## Concepts Covered
- **Anchor Tags (`<a>`)**: Create hyperlinks
  - External links: `<a href="http://website.com">Link</a>`
  - Internal links: `<a href="#section-id">Link</a>`
- **Named Anchors**: Use `id` attribute to create bookmark targets
- **Navigation**: Jump to specific sections within a page

## Example Usage
```html
<!-- Create a bookmark target -->
<h2 id="section1">Introduction</h2>

<!-- Link to that bookmark -->
<a href="#section1">Go to Introduction</a>
```
