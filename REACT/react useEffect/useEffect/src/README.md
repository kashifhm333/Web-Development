# react useEffect/useEffect/src

This folder contains the source code for the useEffect example.

Key files:
- [App.jsx](App.jsx) demonstrates different dependency-array patterns.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the page.
- [index.css](index.css) provides global styles.
- [components/README.md](components/README.md) explains the NavBar component.

What it demonstrates:
- mount-only effects
- dependency-based effects
- cleanup functions
