# video 117 useMemo/src

This folder contains the source code for the useMemo performance example.

Key files:
- [App.jsx](App.jsx) memoizes an expensive calculation.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the page.
- [index.css](index.css) provides global styles.

What it demonstrates:
- memoized derived values
- dependency arrays
- avoiding unnecessary recalculation
