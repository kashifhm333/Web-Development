# first

This project is a small React demo that shows component composition, basic state, and simple event handling.

Key files:
- [src/README.md](src/README.md) explains the App, `main.jsx`, and styling files.
- [documents/README.md](documents/README.md) explains the NavBar and Footer components.

What it demonstrates:
- `useState` for a counter
- Parent-to-child component composition
- JSX rendering and button clicks

Run it with:
```bash
npm install
npm run dev
```
