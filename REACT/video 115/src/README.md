# video 115/src

This folder contains the React Router example source code.

Key files:
- [App.jsx](App.jsx) sets up routes and layout.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the app.
- [index.css](index.css) provides global styles.
- [components/README.md](components/README.md) explains the Navbar and links.

What it demonstrates:
- React Router navigation
- route-based UI changes
- client-side links
