# video 116 without useContext/src

This folder contains the prop-drilling version of the counter example.

Key files:
- [App.jsx](App.jsx) owns the count state.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the page.
- [index.css](index.css) provides global styles.
- [components/README.md](components/README.md) explains the nested component chain.

What it demonstrates:
- passing props through multiple layers
- why Context API can be useful
- component separation
