# video 116 without useContext/src/components

This folder contains the components that pass the count prop downward.

Key files:
- [Button.jsx](Button.jsx) passes the prop to Component.
- [Component.jsx](Component.jsx) displays the count.
- [Navbar.jsx](Navbar.jsx) forwards the prop through the tree.

What it demonstrates:
- prop drilling
- child-to-child value forwarding
