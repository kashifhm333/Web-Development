# video 110 conditional rendiring/src

This folder contains the React source for the conditional rendering example.

Key files:
- [App.jsx](App.jsx) shows ternaries, `&&`, and list rendering.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the UI.
- [index.css](index.css) provides global styles.

What it demonstrates:
- state-driven rendering
- list rendering with `map`
- multiple conditional UI patterns
