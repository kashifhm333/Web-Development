# video 112/src

This folder contains the React event-handling example.

Key files:
- [App.jsx](App.jsx) manages form state and hover events.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the page.
- [index.css](index.css) provides global styles.

What it demonstrates:
- `onChange`
- `onMouseOver`
- object state updates with spread syntax
