# video 116 with useContext/src

This folder contains the source code for the Context API example.

Key files:
- [App.jsx](App.jsx) provides the context value.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the page.
- [index.css](index.css) provides global styles.
- [components/README.md](components/README.md) explains the nested components.

What it demonstrates:
- Context.Provider usage
- useContext consumption
- avoiding prop drilling
