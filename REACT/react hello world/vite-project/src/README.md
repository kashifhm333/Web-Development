# react hello world/vite-project/src

This folder contains the source code for the hello world React example.

Key files:
- [App.jsx](App.jsx) renders the counter and Navbar.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the UI.
- [index.css](index.css) holds global styles.
- [component/README.md](component/README.md) explains the Navbar component.

What it demonstrates:
- useState for a counter
- props passing to a child component
- basic JSX structure
