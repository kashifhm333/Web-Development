# component props and JSX/vite-project/src

This folder contains the React source for the props and JSX example.

Key files:
- [App.jsx](App.jsx) renders multiple Card components.
- [main.jsx](main.jsx) mounts the app.
- [App.css](App.css) styles the card layout.
- [index.css](index.css) provides global styles.
- [components/README.md](components/README.md) explains the reusable Card component.

What it demonstrates:
- passing data through props
- rendering the same component with different values
- keeping UI logic in small reusable pieces
